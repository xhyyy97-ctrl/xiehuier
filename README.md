# 歇会儿

一款轻量的 macOS 菜单栏休息提醒工具。

## 功能

- 常驻菜单栏，不打扰桌面
- 按设定周期提醒休息
- 支持稍后提醒、跳过本次、开始休息
- 支持休息倒计时和休息结束提醒
- 支持通知测试，方便确认系统通知是否正常

## 系统要求

- macOS 12.5 及以上
- 支持 Intel 和 Apple Silicon

## 下载

下载最新版请前往 GitHub 的 Releases 页面。

## 首次打开

1. 解压下载得到的压缩包
2. 打开“歇会儿.app”
3. 如果系统提示安全限制，按提示允许打开
4. 第一次运行后，到系统设置里允许它发送通知

## 说明

- 这是菜单栏应用，启动后主要显示在屏幕顶部菜单栏
- 如果看不到主窗口，请点击菜单栏里的“歇会儿”
