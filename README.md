# 歇会儿

![Uploading image.png…]()

一款轻量、安静、好看的 macOS 菜单栏休息提醒工具。

它不会占着桌面，也不会逼你改工作方式，只是在合适的时候提醒你停一下、歇一会儿，再继续下一轮专注。

## 适合谁

- 长时间坐在电脑前工作的人
- 经常一忙就忘记休息的人
- 想要一个简单提醒工具，不想装复杂效率系统的人

## 功能亮点

- 常驻菜单栏，打开即用，不打扰当前工作
- 自定义提醒周期，决定多久提醒一次休息
- 自定义休息时长，适合不同节奏的工作方式
- 支持稍后提醒，一键延后 5 / 10 / 15 分钟
- 支持跳过本次提醒，不影响下一轮计时
- 支持休息倒计时和休息结束提醒
- 支持通知测试，方便确认系统通知是否正常
- 界面清爽，适合作为日常常驻小工具

## 使用方式

1. 启动应用后，它会常驻在屏幕顶部菜单栏
2. 到时间后会提醒你休息一下
3. 你可以直接开始休息，也可以稍后提醒或跳过本次
4. 休息结束后，会自动开始下一轮专注计时

## 界面说明

- 主界面会显示当前状态、距离休息的倒计时，以及下一次提醒信息
- 设置页可以直接调整提醒周期、休息时长和稍后提醒时长
- 整体交互偏轻量，适合快速查看和快速操作

## 系统要求

- macOS 12.5 及以上
- 支持 Intel 和 Apple Silicon

## 下载

下载最新版请前往 GitHub 的 Releases 页面。

## 首次打开

1. 解压下载得到的压缩包
2. 打开“歇会儿.app”
3. 如果系统提示安全限制，按提示允许打开
4. 第一次运行后，到系统设置里允许它发送通知

## 说明

- 这是菜单栏应用，启动后主要显示在屏幕顶部菜单栏
- 如果看不到主窗口，请点击菜单栏里的“歇会儿”
- 如果通知图标显示不正常，退出应用后重新打开一次即可
